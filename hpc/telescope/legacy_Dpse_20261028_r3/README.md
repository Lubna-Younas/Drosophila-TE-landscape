# Historical Telescope source snapshot

Executed controller: `te_expression_recovery_20261028_r3_Dpse`.

These are source/provenance snapshots. Copy and configure `plan.example.json`
as `plan.json` in a fresh controller; independently rebuild input manifests and
package identities before execution. `package_checksums.original.json` records
the original package and cannot validate edited configuration or republished
path placeholders. The original private manifests, runtime receipts and
generated job scripts are not silently recreated by this repository.

This folder explains earlier output versions and recovery; it is not an instruction to repeat completed work.
